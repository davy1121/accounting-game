# 会计准则妙妙屋 · 资产减值互动影游

研究生课程《会计准则》资产减值专题的互动学习站点。

## 内容

- 7 个准则首页 + 资产减值详情页
- 59 页课程课件（.pptx）
- 案例视频
- 三贤者试炼（3 条路 × 3 题，答对得道具）
- 互动影游（20 段视频、10 个关键抉择、4 个结局）

## 三个入口

| 页面 | 用途 |
|---|---|
| `index.html` | 站点首页 |
| `学生端.html` | 学生扫码后输学号进入 |
| `教师端.html` | 老师查看成绩排名 |

## 数据

成绩存在 Supabase（`results` 表），配置见 `成绩.js`。
上课前重置：Supabase → SQL Editor → `delete from results;`

## 排名规则

分数降序；分数相同时，答题用时短的靠前。
